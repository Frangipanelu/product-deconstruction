# 参考风格网站

分析报告写作时参考这些网站的风格和方法论。

| 网站 | 特点 | 适合学习 |
|------|------|----------|
| Stratechery (stratechery.com) | 长文科技战略分析 | 论点组织和判断力 |
| Product Hunt (producthunt.com) | 极简产品卡片+数据 | 信息展示密度 |
| Similarweb (similarweb.com) | 数据仪表板可视化 | 图表布局和数据叙事 |
| 人人都是产品经理 (woshipm.com) | 中文产品分析社区 | 报告结构和框架 |
| UserOnboard (useronboard.com) | 截图标注式拆解流程 | 交互拆解表达 |
