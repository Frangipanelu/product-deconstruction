Section 01

产品速览

GrowthOS 是一个基于 MCP（Model Context Protocol）的开源分析服务器，旨在让 AI Agent 能够直接访问产品分析数据、用户行为指标和增长实验结果。它将传统 BI 工具的能力暴露为标准化的 MCP 工具，使 AI 助手可以自然语言查询业务数据。

核心定位

  • MCP 协议生态中的数据分析层
  • 为 AI Agent 提供结构化数据访问
  • 替代传统 BI 仪表盘的对话式查询
  • 开源、可自部署、MIT 协议

技术栈

  • TypeScript / Node.js 运行时
  • MCP SDK 集成
  • 支持 ClickHouse / PostgreSQL
  • REST API 数据源适配

目标用户

  • 增长工程师与数据分析师
  • AI 应用开发者
  • 产品团队与运营团队
  • SaaS / 互联网产品团队

项目状态

  • 早期阶段（25 Stars / 7 Commits）
  • 功能框架已搭建，工具数量丰富
  • 社区尚在培育期
  • 文档与示例有待完善
Section 02

JTBD 分析

用户在什么场景下「雇佣」GrowthOS 来完成什么任务？

1
当我需要分析用户留存数据时，我希望能直接用自然语言向 AI 提问，这样我就能省去写 SQL 和搭建仪表盘的时间，快速获得洞察。
2
当我在构建 AI 驱动的增长工具时，我希望有一个标准化的数据接口层，这样我就能让 Agent 直接访问分析数据而无需手动集成。
3
当我需要监控实验结果和 A/B 测试指标时，我希望AI 能自动拉取最新数据并总结趋势，这样我就能更快做出产品决策。
4
当我需要跨多个数据源做归因分析时，我希望有一个统一的查询入口，这样我就能避免在多个工具之间切换和手动拼接数据。
5
当我想把分析能力嵌入自己的 AI 产品时，我希望有一个开源可嵌入的方案，这样我就能避免从零构建数据访问层。

Section 05

SWOT 分析 + 综合评分

Strengths 优势

  • MCP 原生架构，卡位精准
  • 49 个工具覆盖面广
  • MIT 开源，社区友好

Threats 威胁

  • 大厂快速推出 MCP 集成
  • MCP 协议本身仍在演进
  • 数据安全与合规风险
  • 用户习惯迁移成本高
