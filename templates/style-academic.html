01 — 产品速览

产品速览

💡 设计亮点
所有 Tool 均遵循 无状态设计——参数即查询，不持有会话状态。这使得 Agent 可以在任意上下文中自由组合调用，无需担心状态同步问题，天然适合多步推理工作流。
⚠️ 当前限制
实验管理模块尚不支持样本量计算和实验互斥组配置，复杂实验场景仍需回退到传统平台操作。

05 — SWOT + 评分

SWOT 分析与综合评分

S — 优势

  • 工具数量领先，覆盖归因+实验+分群全链路
  • MIT 开源，无厂商锁定风险
  • 无状态设计，天然适配 Agent 工作流
  • 专注 MCP 协议，技术栈现代

W — 劣势

  • 项目极早期（7 commits），稳定性未经验证
  • 社区规模小（25 Stars），生态影响力有限
  • 缺乏企业级安全与权限控制
  • 文档与示例覆盖度不足

O — 机会

  • MCP 协议生态爆发，工具层需求激增
  • 企业 AI Agent 落地需要数据分析能力
  • 可与 LangChain / CrewAI 等框架深度集成
  • 数据隐私合规场景下的自托管需求

T — 威胁

  • PostHog 等成熟产品的 MCP 扩展快速迭代
  • MCP 协议标准本身仍在演进，兼容性风险
  • 大厂可能推出闭源竞品挤压空间
  • 开源项目维护者精力有限
