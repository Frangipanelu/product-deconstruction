# 产品概述

GrowthOS 是一个开源的 MCP (Model Context Protocol) 分析服务器，为 AI 应用提供行为追踪、性能监控和成本分析能力。项目采用 Apache 2.0 许可证，目前处于 v0.9.2 版本。

# 核心功能

GrowthOS 提供三个主要工具（Tools），均通过 MCP 协议暴露给 AI 客户端。

工具清单

track_event — 记录用户行为事件，支持自定义属性和自动会话关联
query_metrics — 查询聚合指标，支持时间范围、分组和过滤条件
create_alert — 创建阈值告警，支持费用、延迟、错误率等指标

事件数据结构

{
  "event": "api_call",
  "user_id": "usr_abc123",
  "properties": {
    "model": "claude-3-opus",
    "tokens_in": 1250,
    "tokens_out": 890,
    "latency_ms": 2340,
    "cost_usd": 0.089
  },
  "timestamp": "2026-09-07T14:30:00Z"
}

查询示例

// 查询过去 7 天的每日 API 调用量和费用
const result = await client.callTool({
  name: "query_metrics",
  arguments: {
    metric: "api_call",
    group_by: "day",
    range: "7d",
    aggregations: ["count", "sum:cost_usd"]
  }
});

# SWOT 分析

Strengths (优势)

  • MCP 协议原生支持，开箱即用
  • 轻量级，SQLite 模式零依赖部署
  • TypeScript 全栈，类型安全
  • Apache 2.0 许可，企业友好

Weaknesses (劣势)

  • v0.x 版本，API 稳定性未保证
  • 文档覆盖率不足，示例较少
  • 无官方 SDK，客户端需手动构建
  • 存储层未支持 ClickHouse 等 OLAP

Opportunities (机会)

  • MCP 生态快速增长，先发优势明显
  • AI 应用可观测性需求爆发
  • 可扩展为 AI Agent 编排平台
  • 与 LangChain/LlamaIndex 集成

Threats (威胁)

  • 大型厂商自建内部方案
  • Langfuse 等项目增加 MCP 支持
  • MCP 协议标准可能变更
  • 数据隐私法规趋严

# 结论

GrowthOS 在 MCP 可观测性赛道占据先发位置，产品完成度较高，技术选型务实。核心风险在于 v0.x 阶段的 API 稳定性和生态护城河深度。
